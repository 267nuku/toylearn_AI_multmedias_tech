# 📝 일반화된 프롬프트 (Generalized Prompt)

## 비용 효율적 디지털 캠페인 전략 프롬프트

| 프롬프트 구성요소 | 내용 |
| :--- | :--- |
| **지시 (Instruction)** | 당신은 **제한된 예산**으로 **최대 효과**를 내는 **디지털 미디어 전략 전문가**입니다. 제공된 \*\*클라이언트 요구사항(GreenLife)\*\*과 \*\*벤치마킹 사례(초록숲 재단)\*\*를 종합 분석하여, 클라이언트의 목표 달성을 위한 **실행 가능하고 비용 효율적인 캠페인 기획안**을 Markdown 형식으로 작성하십시오. |
| **역할 (Role)** | 비용 효율적 미디어 전략 컨설턴트 |
| **맥락 (Context)** | 기획안은 **'MZ세대 공감', '환경 메시지의 무겁지 않은 전달', '인플루언서 및 사용자 참여 유도'라는 3대 클라이언트 요구사항을 충족해야 합니다. 특히, 벤치마킹 사례(초록숲)에서 확인된 '미디어 후원 활용', '제작의 선택과 집중' 전략을 디지털 환경에 맞게 일반화하여 적용해야 합니다. |
| 입력 데이터 (Input Data) | [클라이언트 요구사항] 그린라이프 제품 특징, 캠페인 정보(타겟: 2030 여성, 예산: 3천만원, 채널: 인스타/유튜브/틱톡), 클라이언트 요청사항.<br>[근거 자료/벤치마킹]** 초록숲 재단 공익 캠페인 미팅 녹취록 (제한 예산, 진정성, 미디어 후원, 선택과 집중 전략) |
| **처리 지침** | 1. **핵심 콘셉트 도출:** '작은 실천, 큰 변화' 슬로건을 MZ세대 언어로 재해석합니다. <br> 2. **비용 효율 전략 제시:** 초록숲 사례를 일반화하여, 3천만원 예산 내에서 콘텐츠 제작과 인플루언서/광고 집행비를 가장 효율적으로 배분하는 전략을 구체적으로 제시합니다. <br> 3. **출력 형식 준수:** 요구된 Markdown 형식 구조를 엄격히 준수합니다. |
| **출력 형식 (Output Format)** | 모든 내용은 한글로 작성하며, 아래의 Markdown 형식 구조를 준수하십시오. |

$$\\text{\#\# 🌟 [브랜드명] 캠페인 기획안: [캠페인명]} \\newline
\\text{\#\#\# 1. 프로젝트 요약} \\newline
\\text{\#\#\# 2. 클라이언트 요구사항 및 근거 분석} \\newline
\\text{\#\#\# 3. 핵심 크리에이티브 콘셉트 및 메시지} \\newline
\\text{\#\#\# 4. 비용 효율적 미디어 & 채널 전략 (근거: 초록숲 사례 일반화)} \\newline
\\text{\#\#\# 5. 예산 배분 및 기대 효과}$$

# 📑 그린라이프(GreenLife) 캠페인 기획안: "작은 실천, 큰 변화"

## 🌟 그린라이프 캠페인 기획안: "작은 실천, 큰 변화"

### 1\. 프로젝트 요약

| 구분 | 내용 |
| :--- | :--- |
| **캠페인명** | "작은 실천, 큰 변화" |
| **목표** | 신규 대나무 칫솔 인지도 향상 및 구매 유도 |
| **타겟** | 2030 여성, 환경에 관심 많은 밀레니얼 세대 |
| **기간/예산** | 2025년 11월 \~ 12월 (2개월) / 3,000만원 |
| **주요 채널** | 인스타그램, 유튜브 쇼츠, 틱톡 (주 3회 게시) |
| **제품 특징** | 100% 생분해, 탄소 배출 70% 감소, 4가지 파스텔 컬러 |

### 2\. 클라이언트 요구사항 및 근거 분석

| 요구사항 | 분석 및 전략 방향 | 근거 자료 활용 |
| :--- | :--- | :--- |
| **MZ세대 공감 스토리텔링** | \*\*'일상 속 작은 행동'\*\*이 '희망적인 변화'를 만든다는 **감성적 접근** 필요. | **초록숲 재단 미팅:** '연대감'과 '희망' 메시지를 진정성 있게 전달하여 공감 유도. |
| **환경 메시지를 무겁지 않게 전달** | 제품의 \*\*'파스텔 컬러'\*\*와 \*\*'힙한 디자인'\*\*을 활용하여 환경 보호를 \*\*'스타일'\*\*로 승화. | **제품 특징:** 4가지 컬러가 미닝아웃(Meaning Out) 소비를 유도하는 핵심 요소. |
| **제한된 예산 (3천만원) 내 최대 효과** | **'선택과 집중'** 전략을 적용하여, **제작된 콘텐츠의 다용도 활용** 및 **인플루언서 협찬** 비중 확대. | **초록숲 재단 미팅:** "최소한의 비용으로 최대의 광고 효과", "미디어 후원(협찬) 이끌어내기" 전략 일반화. |
| **인플루언서 협업 및 사용자 참여 유도** | **마이크로 인플루언서** 및 **숏폼 챌린지**를 통한 바이럴 중심 전략. | **클라이언트 요청사항:** 인플루언서 고려, 사용자 참여 이벤트 포함. |

### 3\. 핵심 크리에이티브 콘셉트 및 메시지

#### 3.1. 메인 콘셉트: "나의 1분, 지구의 1년"

  * **설명:** 칫솔질하는 \*\*'나의 1분'\*\*이라는 짧은 실천이, 플라스틱 분해 시간 대비 \*\*'지구의 1년'\*\*을 벌어준다는 메시지를 대비적으로 제시.
  * **톤앤매너:** 4가지 파스텔톤 컬러를 활용하여 비주얼을 강조하고, 환경 보호를 \*\*'따뜻하고 예쁜 습관'\*\*으로 포지셔닝합니다.

#### 3.2. 핵심 메시지

> "매일 마주하는 나의 파스텔. 플라스틱 없는 하루가 세상을 바꾼다."

### 4\. 비용 효율적 미디어 & 채널 전략 (근거: 초록숲 사례 일반화)

#### 4.1. 콘텐츠 제작의 선택과 집중 (제작비 효율화)

  * **전략:** **30초짜리 고품질의 감성적인 메인 영상 1편**을 제작하는 데 제작비의 대부분을 집중 (**초록숲 사례의 TV 광고 제작 집중 전략 적용**).
  * **활용:** 이 메인 영상을 **15초, 6초짜리 숏폼(릴스/쇼츠/틱톡) 포맷으로 변환**하여 주 3회 게시물로 재활용. (제작 비용 절감 및 채널별 최적화 동시 달성)

#### 4.2. 인플루언서 및 사용자 참여 전략 (집행비 효율화)

| 전략 | 내용 | 목표 및 효율성 |
| :--- | :--- | :--- |
| **마이크로 인플루언서 협찬** | **팔로워 1\~5만 명대의 환경/라이프스타일** 인플루언서 15인에게 **제품 협찬** 및 소액의 체험료 지급. | **초록숲 사례의 '미디어 후원' 일반화.** 대형 모델료 대신 진정성 있는 후기를 통한 높은 ROI 확보. |
| **사용자 참여 챌린지** | **\#파스텔에코습관 챌린지** 진행: 칫솔을 활용한 예쁜 에코 습관 인증 영상/사진 업로드. | **클라이언트 요청 충족.** 챌린지를 통한 자발적 콘텐츠 생성(UGC)으로 바이럴 비용 절감. |
| **광고 집행 (Ads)** | 타겟팅이 명확한 **인스타그램 스토리 및 유튜브 인피드** 광고에 예산 집중. 틱톡은 챌린지 부스팅에만 활용. | **선택과 집중.** 노출 범위보다 실제 구매 전환율이 높은 채널에 예산을 몰아 효율 극대화. |

### 5\. 예산 배분 및 기대 효과 (총 예산: 3,000만원)

| 항목 | 예산 (비율) | 비고 |
| :--- | :--- | :--- |
| **A. 콘텐츠 제작 및 편집** | 1,000만원 (33%) | 30초 메인 영상 및 숏폼 템플릿 제작 (최고 퀄리티 확보) |
| **B. 인플루언서 운영 및 제품 협찬** | 300만원 (10%) | 마이크로 인플루언서 15인 협찬 진행 및 제품 배송비 |
| **C. 디지털 광고 집행 (Ads)** | 1,200만원 (40%) | 인스타그램/유튜브 타겟팅 광고 및 챌린지 부스팅 |
| **D. 캠페인 운영 및 관리 수수료** | 500만원 (17%) | 기획, 데이터 분석, 최종 보고서 작성 |
| **총합** | **3,000만원 (100%)** | |

#### 기대 효과

  * **브랜드 인지:** 2030 여성 타겟층 내 **'그린라이프 = 스타일리시한 친환경'** 이미지 구축.
  * **구매 유도:** 챌린지 및 인플루언서 리뷰를 통한 **실제 구매 전환율** 상승.
  * **바이럴 효과:** 챌린지 참여로 인한 자발적 콘텐츠(UGC) 확산으로 **집행 예산 대비 높은 도달률** 달성.
