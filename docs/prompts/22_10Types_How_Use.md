## 📝 작성 위해 추가 필요 요건

AI가 성공적으로 목표한 프로토타입 코드를 생성하려면, 캔바 디자인을 하듯이 **구성 요소와 레이아웃**에 대한 명확한 지침이 필요합니다.

1.  **레이아웃 구조 정의:**
      * **2단 레이아웃(좌/우)** 또는 **3단 레이아웃(헤더/본문/사이드바)** 중 신속하게 구현할 수 있는 명확한 구조를 제시해야 합니다. (예: 왼쪽 넓은 영역은 영상 플레이어, 오른쪽은 댓글/데이터 테이블)
2.  **핵심 기능의 시각적 요소 정의:**
      * '영상 플레이어 영역', '타임스탬프 댓글 기능', '승인/반려 버튼' 등의 위치와 스타일을 구체적으로 명시해야 합니다.
3.  **사용 라이브러리 지정 (선택적):**
      * **부트스트랩(Bootstrap)** 또는 \*\*테일윈드(Tailwind CSS)\*\*와 같은 프론트엔드 프레임워크 사용을 명시하여 **다크 모드**와 **직관적인 UI**를 신속하게 구현하도록 지시합니다. (캔바에서도 템플릿을 고르듯, AI에게도 빠른 '스타일 가이드'를 제시하는 것과 같습니다.)

## 💡 문제 해결 프롬프트

저는 누쿠님의 3년 차 프론트엔드 개발자 페르소나에 완벽히 몰입하여, 필수 요건을 모두 담은 프롬프트를 다음과 같이 작성했습니다.

> **[역할 부여]** 당신은 **사용자 경험(UX)과 빠른 프로토타이핑에 능숙한 3년 차 프론트엔드 개발자**입니다.
>
> **[목표]** 오늘 오후 4시 회의에서 기획팀, 디자인팀, 운영팀의 의견을 조율하기 위해 **단일 HTML 파일 내에 모든 코드(HTML, CSS, JS)가 포함된** '사내 영상 리뷰 및 승인용 웹 대시보드' 프로토타입 코드를 신속하게 생성해야 합니다.
>
> **[제약 및 요구사항]**
>
> 1.  **스타일:** \*\*트렌디한 다크 모드(Dark Mode)\*\*를 메인 테마로 적용하십시오. 반응형 디자인(RWD)까지는 불필요하나, 데스크톱 환경에서 **직관적인 UI**를 제공해야 합니다.
> 2.  **구조:** 화면을 크게 2단으로 나눕니다.
>       * **좌측 (70%):** 넓은 영역을 차지하는 영상 플레이어 영역(임시 `<iframe>` 또는 `<div>`로 표시)을 배치합니다.
>       * **우측 (30%):** '리뷰 데이터 섹션'을 배치하며, 상단에는 \*\*승인/반려 버튼(Primary/Danger 스타일)\*\*을, 하단에는 **타임스탬프 댓글 목록** 기능을 위한 데이터 밀집형 테이블/목록을 배치합니다.
> 3.  **기술 스택:** **CDN 방식의 Bootstrap 5**를 사용하여 신속하게 UI 컴포넌트와 다크 모드 스타일을 적용합니다. 모든 코드는 **단일 파일 내에 인라인으로 작성**되어야 합니다.
> 4.  **출력 형식:** 코드만 출력하며, 코드에 대한 설명이나 서론/결론 문구는 일절 제외합니다.

## 🌟 프롬프트 실행 결과 (예상)

위 프롬프트를 AI 모델에 입력했을 때, 다음과 같은 구조의 HTML 코드가 출력될 것으로 예상됩니다.

  * **HTML:** `<head>` 태그 내에 Bootstrap 5 CDN 링크와 `<style>` 태그에 다크 모드 CSS가 포함됩니다.
  * **CSS:** 전체 `<body>`에 `background-color: #212529` (다크 모드 배경색)가 적용되고, 폰트 색상은 밝게 설정될 것입니다.
  * **JS:** 승인/반려 버튼 클릭 시 간단한 알림창을 띄우는 정도의 기본 상호작용(인터랙션) 코드가 포함될 수 있습니다.

**결과물의 핵심 구조:**

```html
<!DOCTYPE html>
<html lang="ko">
<head>
    </head>
<body class="bg-dark text-light">
    <div class="container-fluid p-3">
        <div class="row">
            <div class="col-md-8">
                <div class="card bg-darker">
                    </div>
            </div>

            <div class="col-md-4">
                <div class="mb-3">
                    <button class="btn btn-success">승인</button>
                    <button class="btn btn-danger">반려</button>
                </div>

                <div class="card bg-darker">
                    </div>
            </div>
        </div>
    </div>
    </body>
</html>
```

이렇게 명확하게 구조화된 코드는 회의 시간에 팀원들의 즉석 수정 요청(예: "댓글 테이블 컬럼 하나 추가", "승인 버튼 색상 변경")을 개발자가 신속하게 반영할 수 있는 최적의 기반이 될 것입니다\!
